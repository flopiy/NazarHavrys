# 🧙‍♂️ Fungal Curse: Echoes of the Mire (The Midnight Bramble)

Двовимірний (2D) темний фентезі-екшн/платформер з елементами магії, розроблений на рушії **Unity 6 (6000.3.10f1)** із застосуванням **Universal Render Pipeline (URP 2D)** та **New Input System**.

---

## 📖 Огляд гри

**Fungal Curse: Echoes of the Mire** — це динамічний платформер, де гравець керує тендітною, але могутньою чарівницею, яка прокладає собі шлях крізь заражені містичним грибком та темрявою болота (*Midnight Bramble*). 

Гравцеві доведеться долати смертоносні пастки, розбивати перешкоди, збирати реліквії для відкриття порталів, боротися з гоблінами й елітними монстрами та здолати фінального боса.

---

## ✨ Ключові особливості

- **Чутлива та точна фізика руху:** пряме керування швидкістю через `linearVelocity`, плавне прискорення, налаштована гравітація при падінні (`fallMultiplier`), буферизація стрибка та coyote time.
- **Бойова магічна система:**
  - 🏹 **Magic Arrow (Магічна стріла)** — швидкий далекобійний снаряд з арканним світінням.
  - ⚡ **Spike Storm (Шторм шипів)** — закляття масового ураження (AoE), що скидає гострі шипи на ворогів з можливістю вибору кількості снарядів (1–9).
  - 🛡️ **Magic Shield (Магічний щит)** — енергетичний купол, що повністю блокує будь-яку шкоду за рахунок швидкого споживання мани.
  - 🌀 **Blink / Teleport (Телепортація)** — миттєве просторове переміщення вперед із перевіркою стін через `Raycast2D`, щоб запобігти застряганню в колайдерах.
- **HUD та візуальний зворотний зв'язок:**
  - Шкали здоров'я (HP), мани (Mana) та витривалості (Stamina).
  - Лічильник життів (система 3 життів на сесію).
  - Панель здібностей у правому нижньому кутку з відображенням перезарядок (cooldowns), вартості мани/витривалості та можливістю активації як гарячими клавішами, так і кліком миші.
  - Індикатори здоров'я над ворогами (Enemy Health Bars) та ефект спалаху при отриманні шкоди.
- **Прогресія та покращення (Meta-progression):**
  - Отримання досвіду (XP) та очок покращень за знищення ворогів та збирання предметів.
  - Меню прокачування характеристик (Швидкість бігу, Максимальна мана, Сила атаки, Дистанція телепортації, Висота стрибка) до 5 рівнів.
  - Внутрішньоігровий левелап із відновленням і збільшенням ресурсів.
- **Рівні та кампанія:**
  - 4 унікальні рівні з поступовим зростанням складності та фінальним босом на 4-му рівні.
  - Система вибору рівнів (`LevelSelect`) із збереженням розблокованого прогресу.
  - Механіка збору предметів (`MissionManager`) для активації вихідного порталу на кожному рівні.
- **Графіка та освітлення URP 2D:**
  - Pixel-perfect рендеринг (16 PPU).
  - 2D джерела світла (Point Light 2D, Global Light 2D) та режим змішування (Multiply/Additive) для створення атмосфери похмурого болота.
  - Багатошаровий безкінечний паралакс-фон (`ParallaxController`, `InfiniteParallax`).
  - Пост-обробка через Global Volume (Vignette, Color Adjustments, Contrast).
- **Налаштування гри:**
  - Меню налаштувань із регулюванням гучності звуку (`Master Volume`), повноекранного режиму (`Fullscreen`), якості графіки та можливістю повного скидання прогресу.

## 🎮 Керування (Controls)

| Дія | Клавіатура / Миша | Опис |
| :--- | :--- | :--- |
| **Рух ліворуч / праворуч** | `A` / `D` або `←` / `→` | Горизонтальне переміщення чарівниці |
| **Стрибок** | `Space` / `W` / `↑` | Стрибок персонажа з перевіркою поверхні |
| **Магічна стріла (Attack)** | `Ліва кнопка миші (LMB)` | Базовий магічний постріл |
| **Телепортація (Blink)** | `Left Ctrl` / `Left Shift` | Миттєвий ривок у напрямку погляду |
| **Шторм шипів (Spike Storm)** | `Q` або `Права кнопка миші (RMB)` | Виклик граду шипів на найближчого ворога |
| **Вибір кількості шипів** | `Q` + Цифри `1`–`9` | Затисніть цифру під час натискання Q |
| **Магічний щит (Magic Shield)** | `F` | Створення захисного бар'єра |
| **Клік по здібностях на HUD** | `LMB` по іконках | Активація заклять через інтерфейс |

## 📈 Система прокачування (Upgrades)

За знищення ворогів нараховуються очки покращень (`UpgradePoints`), які можна витратити у вікні **Покращення** (`Upgrades`):

1. 🏃 **Швидкість бігу (Speed):** +0.2 до базової швидкості за рівень (макс. 5 рівнів).
2. 🔷 **Максимальна мана (Max Mana):** +10 до запасу мани за рівень (макс. 5 рівнів).
3. ⚔️ **Сила атаки (Attack Damage):** +1 до шкоди стріли та шипів за рівень (макс. 5 рівнів).
4. 🌀 **Дистанція телепортації (Blink Distance):** +0.3 до дальності переміщення за рівень (макс. 5 рівнів).
5. 🦘 **Висота стрибка (Jump Velocity):** +0.3 до сили стрибка за рівень (макс. 5 рівнів).

## 🗺️ Структура рівнів

1. **MidnightBramble_Level1:** Вступний рівень — ознайомлення з механіками руху, стрибками, базовими ворогами та збором предметів для відкриття порталу.
2. **MidnightBramble_Level2:** Платформінгові виклики — небезпечні пастки, шипи, токсичні зони, руйнівні стіни та спавнери ворогів.
3. **MidnightBramble_Level3:** Підвищена складність — групи елітних гоблінів, міні-боси з підвищеним здоров'ям та шкодою.
4. **MidnightBramble_Level4 (Boss):** Фінальне протистояння з головним босом (збільшений у 2 рази розмір, ×5 HP, ×3 атака, 500 очок нагороди).

## 👾 Вороги

- **Goblin Thief / Базовий гоблін (`GoblinAI`):**
  - Патрулювання платформ з детекцією країв (`EdgeCheck`) та стін (`WallCheck`).
  - Чотирифакторний FSM (Patrol → Anticipation → ActiveStrike → Recovery).
  - Контактна шкода при зіткненні.
- **Міні-бос (`EliteEnemyAI`, isMiniBoss):**
  - ×2.5 здоров'я, ×2 шкоди, збільшений масштаб на 40%, нагорода: 120 очок/XP.
- **Головний Бос (`EliteEnemyAI`, isBoss):**
  - ×5 здоров'я, ×3 шкоди, збільшений масштаб у 2 рази, нагорода: 500 очок/XP.

## ⚙️ Технічні деталі та оптимізація

- **Unity Version:** 6000.3.10f1 (Unity 6)
- **Render Pipeline:** Universal Render Pipeline (URP 2D)
- **Input System:** Unity New Input System (`InputSystem_Actions.inputactions`)
- **Physics 2D:** 
  - `CompositeCollider2D` з `Geometry Type = Polygons` для безшовного тайлмапу без застрягань на стиках тайлів.
  - Нульове тертя (`ZeroFriction.physicsMaterial2D`) на колайдері гравця для плавного ковзання.
- **Оптимізація пам'яті:**
  - GC-free пулінг снарядів (`ObjectPooler` + `IPooledObject`).
  - Кешування компонентів в `Awake` — жодних викликів `GetComponent` або `FindObjectOfType` у циклах `Update`/`FixedUpdate`.
  - Безпечне видалення 2D-скелетних анімацій (`SpriteSkin.enabled = false` перед знищенням об'єкта) для запобігання пошкодженню буфера деформації Unity 2D Animation.

## 🚀 Встановлення та запуск у Unity

1. Встановіть **Unity 6000.3.10f1** (через Unity Hub).
2. Клонуйте або відкрийте проект у Unity Hub.
3. Переконайтеся, що в **Project Settings ▸ Graphics** обрано пайплайн `UniversalRP.asset`.
4. Для початку гри відкрийте сцену **`Assets/Scenes/MainMenu.unity`** та натисніть кнопку **Play** в редакторі.
